开始玩

先让小祥来到桌面，再按自己的节奏慢慢玩。

软件收费吗？需要登录账号吗？双端+

SakikoPet 是免费的同人桌宠，也是一款低压力的经营小游戏。首次运行不需要登录账号。请从本站的下载区获取文件，不要购买所谓付费激活版。

目前公开介绍以 0.8 为准；旧版本视频和旧手册中的限制可能已经变化。Windows 与 macOS 的界面和系统操作会有所不同。

Windows 下载后怎么打开？能只下载 EXE 吗？Windows+
  1. 把网盘里的整个压缩包下载到电脑，不要使用网盘云解压。
  2. 在本地完整解压到一个新的空文件夹，等待所有文件解压完成。
  3. 从解压后的目录双击 SakikoPet.exe。不要在压缩包预览窗口里直接运行，也不要只拖出 EXE。
  4. 保留程序旁的 Voice 文件夹和其他随包文件。可以给 EXE 创建桌面快捷方式，但不要单独搬走它。

Windows 版面向 64 位 Windows 10 / 11，旧版 Windows 7 不在支持范围。

Mac 怎么安装？提示无法验证开发者怎么办？macOS+
  1. 下载 Mac 的 DMG，适用于 Apple Silicon（M 系列芯片）、macOS 13 及以上。Intel Mac 不适用此安装包。
  2. 打开 DMG，将 SakikoPet.app 拖到 Applications，等待复制完成。
  3. 若首次启动被系统拦截，按 DMG 内的安装教程和视频操作，使用随包的 打开SakikoPet.command。
  4. 脚本也被拦截时，在「系统设置 → 隐私与安全性」中找到对应提示，选择「仍要打开」，再继续包内步骤。

请确认文件来自可信来源，只针对这个安装包处理；不需要关闭 Mac 的全局安全保护。安装完成后可从「应用程序」打开，DMG 可以推出。

第一次玩应该点哪里？祥子不见了怎么办？双端+

左键点击祥子会互动；按住左键可以拖动她；右键点击打开功能菜单。先试试「状态」「打工」「商店」「背包」，不需要一开始就把所有玩法解锁。

Windows 可从右下角托盘图标选择「找回祥子」，也可检查是否隐藏或暂停；双击托盘图标可以切换显示。Mac 从菜单栏里的祥子图标找回相关操作。不同版本的菜单名称可能略有区别。

新手有什么推荐的游玩顺序？双端+
  1. 让祥子在桌面陪伴，左键互动，熟悉右键菜单。
  2. 打工赚第一笔钱，在状态里查看余额、信任度和阶段。
  3. 到商店买礼物，在背包里使用；状态出现突破按钮时记得完成互动。
  4. 累计打工收入到 10,000 日元后试试股票；第三阶段购入人偶剧场企划书和麦克风。
  5. 剧场里先招募、组队，再挑战合适的舞台。积累粉丝，逐步解锁牧场、笔记本和演出服。
  6. 满足第四阶段条件后，收下回忆册，慢慢等她主动来找你。

不想经营时，也可以只让她安静陪伴。进度不需要赶。

右键菜单为什么少了选项？买了东西却找不到入口？双端+

菜单会随当前动作、形态和解锁进度变化。先检查她是否正在打工、弹琴、说话、暂停、睡觉或进行其他互动，等活动结束再试。

很多玩法是购买后从背包使用对应物品进入：人偶剧场企划书、牧场经营许可证、神秘笔记本、任务清单、小床、共同的回忆都属于这种情况。商店买到物品，不等于已经打开了它的功能。

信任与解锁

卡在第三阶段？先把点数、商品和突破互动分开检查。

怎么提升好感度／信任度？一直挂机有用吗？双端+

界面里的「信任度」就是这里说的好感进度。正常桌面陪伴会逐步积累：第一至第三阶段每 5 分钟约 1 点，第四阶段每 10 分钟约 1 点。这是有效陪伴时间，不是把程序关掉后按现实时间补算。

送礼、喂蛋糕也能增加信任。先到商店购买，再到背包执行可用的赠送或使用操作；不要把「已经买了」和「已经送给她」混为一谈。暂停、隐藏和特殊活动的计时规则可能不同，不建议靠反复重启刷进度。

各阶段需要多少信任？到点会自动升级吗？双端+
目标阶段条件最后一步
第二阶段信任度超过 50到状态页聆听祥子的话
第三阶段信任度超过 100完成对应突破互动
第四阶段信任度达到 300，且已购买共同企划书回到状态页完成突破互动

点数达标不会自动跳阶段。状态里出现「聆听祥子的话」后，需要亲自点它、完成互动。第一次突破还会询问你希望她怎么称呼你。0.8 的信任上限为 400，目前最多第四阶段。

信任度都 400 了，为什么还是第三阶段？双端+

还需要在商店购买「共同企划书」，然后回状态页完成突破。

  1. 先确认关系已到第三阶段。400 是当前上限，第四阶段的点数条件从 300 就已满足。
  2. 在人偶剧场积累超过 10,000 名粉丝，商店才会出现「共同企划书」。
  3. 准备 15,000 日元，在商店购买。它与「人偶剧场企划书」是两件不同的商品。
  4. 回到「状态」，点「聆听祥子的话」，完成关系突破互动，进入第四阶段。

单纯继续挂机、等到 400，或只购买了人偶剧场企划书，都不能代替这一步。突破不会扣掉信任点数。

商店里没有共同企划书，或买了还没到第四阶段？双端+

共同企划书需要剧场粉丝超过 10,000才会出现，不是余额达到 10,000，也不是累计打工收入达到 10,000。刚好 10,000 粉丝也还没达到「超过」条件。

如果已购买，请确认信任达到 300、当前是第三阶段，再到状态页完成「聆听祥子的话」。她忙碌时先结束当前活动。已经买过的商品也可能显示为已售罄；可结合背包和购买状态判断，不必反复购买。

蛋糕有什么用？为什么祥子不肯再吃？双端+

草莓蛋糕在商店购买，到背包使用；除了增加信任，还会让接下来的三次打工得到加成。这不是永久工资升级。

如果还有蛋糕加成没用完，她可能会拒绝继续吃。先正常打工消耗剩余次数，再喂下一块。背包里有蛋糕与身上还有蛋糕加成是两件事。

丰川家的债务买了有什么用？能解锁结局吗？双端+

0.8 手册中，这件 168 亿日元的商品仍没有实质性玩法效果。不要为了它期待立即解锁特殊结局、第四阶段或新功能；第四阶段需要的是「共同企划书」。是否扩展效果以以后公开更新为准。

经营与日常

打工、剧场、牧场和桌面上的小工具。

怎么打工、提前结束和拿到工资？双端+

右键祥子选择「打工」，选好时长后开始；选择不限时打工则需要自己结束。到点返回，或右键选择结束，结算后查看本次收入和状态里的余额。

收起计时窗口不等于结束工作。暂停或隐藏时不把相应时段计为打工时间。普通祥子有不同工作，OB 形态还有「写小说」；弹琴和打工不能同时进行。

股票怎么解锁？为什么买完可用余额变少？双端+

累计打工收入达到 10,000 日元后解锁。右键进入炒股界面，选择股票和投资金额；投入的本金在到期结算前会被冻结，因此不能再当作可花余额。

等待本轮到期，按界面提示领取结算后再进行下一轮。投资有涨有跌，不保证盈利。打工时遇到的股票 NEWS 可以作为下一轮判断线索；没有新闻也不代表稳赚。

人偶剧场怎么玩？招募和选舞台先做哪个？双端+
  1. 第三阶段后购买「人偶剧场企划书」，到背包使用。
  2. 先招募成员、安排阵容，再选择舞台。需要主唱、贝斯、鼓手、主音、副音五个位置齐全；副音空缺时祥子可自动补位。
  3. 按粉丝、余额和阵容能力挑舞台，不必刚解锁就挑战最贵的场地。
  4. 观察舞台偏好与歌单，必要时重新生成歌单；同一场最多免费换三次。
  5. 演出结束后结算流水、租金和粉丝，再为下一场重新选人。

剧场的「？」按钮有详细规则。除祥子外，完成演出的成员会离队，已演出的候选人不能重复使用；尚未使用的候选人不会因为关窗口就消失。

剧场怎么赚更多粉丝？什么是大成功、组合加成？双端+

先选阵容能胜任的舞台，把招募到的候选人灵活分配到不同场次。高级场地租金更高，不代表当前阵容更容易赚钱。歌曲重视的五维属性和阵容匹配程度会影响表现。

流水超过场地租金算成功，达到该舞台的大成功条件还能获得额外流水加成。演出积累粉丝，粉丝又会开放更多舞台和招募方式。CRYCHIC、Ave Mujica、MyGO!!!!! 等特定完整阵容也有组合效果；Ave Mujica 需要的是 Oblivionis，普通 Sakiko 不能直接替代。

剧场里为什么逐渐出现新商品？沙锤和键盘怎么来？双端+

商品按演出经历、成功次数、粉丝和特定角色出场逐步出现。祥子参与成功演出 1 次后可出现沙锤，10 次后出现 ROLAND VR-730，50 次后出现 ROLAND FA-08；首次剧场成功还会开放魔法骰子。

一些舞台的大成功会带来对应商品，特定角色／组合登场会解锁笔记本、天素罗或演出服。解锁后仍要回商店购买；商品描述会说明它是被动效果，还是要在背包使用。

怎么解锁、穿上或脱下 Oblivionis 演出服？双端+

先在人偶剧场组成 CRYCHIC 并实际登场演出，再到商店购买「Oblivionis的演出服」，价格为 200,000 日元。到背包使用一次换装，再使用一次恢复普通祥子。

OB 有不同的点击互动和「写小说」打工，也能弹琴。重启后会恢复普通形态。OB 目前会回应语音唤醒，但不执行后续那句指令；要用截图、快捷回复、music 或启动，请先换回普通装束。

天素罗牧场从哪里进？第一只怎么养？双端+
  1. 先在人偶剧场让 SOYORINS 登场演出。
  2. 商店出现「天素罗」后购买，背包会收到「天素罗牧场经营许可证」。
  3. 在背包使用许可证进入牧场，先免费领取第一只小小。
  4. 购买薯片并选成当前饲料，观察饱腹、心情和成长情况，慢慢照顾它。

0.8 的牧场容量是八只。后续领养、饲料和饲养员都有费用，操作前看清余额与价格。

牧场收入、饲养员、收养客人和图鉴怎么看？双端+

养育天素罗会积累观光收入，记得在牧场领取。饲养员按小时收费，不同饲养员各有说明和能力；当前饲料、库存及饱腹度要一起留意，不要只看拥有几包薯片。

收养客人会按需求报价，先比较客人要求、天素罗情况和报价，再决定是否让伙伴离开。图鉴里的最高收养价格记录的是实际成交价，只查看报价不会刷新纪录；养出过的种类和成年大小也会逐步记录。状态的收支页可查看牧场账本。

怎么让她弹自己的歌？列表为什么是空的？双端+
  1. 右键选择「弹琴」，在播放器中点「打开歌曲文件夹」。
  2. 把自己的 .mp3 或 .wav 放入打开的 songs 文件夹。
  3. 点「刷新播放列表」，选歌后播放。列表最多读取最新 100 首。

不要只改文件扩展名：把其他音频改名为 MP3 不会真的转换格式。播放器可以最小化；想结束弹琴，请右键祥子选择「退出弹琴」。Mac 请使用按钮打开实际歌曲目录，不要照搬 Windows 的程序旁路径。

任务清单怎么用？关掉会丢失吗？双端+

第一阶段起可在商店花 500 日元购买，背包使用后编辑。最多 20 条，每条最多 20 字；拖左侧手柄调整顺序，确认后显示为桌面浮窗。

完成时勾选，误点可以取消；已完成任务会进入「完成回顾」。关闭浮窗只是收起，不会清空全部任务。它是记录你的待办，不是完成后自动发钱的游戏任务系统。

小床怎么摆？怎么叫醒她？双端+

第一阶段起可购买小床，7,500 日元。背包使用后拖到喜欢的位置，再把普通祥子拖上去松手，她就能睡觉。左键叫醒后，等她说完话再下床。

睡着时可以连床一起移动；右键床或再次使用背包物品可以收起。不要放到任务栏／程序坞下面。重启后床先收回背包，再摆放时会记住上次位置。

共同的回忆从哪进？为什么有问号？双端+

第四阶段突破时祥子会赠送「共同的回忆」，说完后点击气泡里的小图标收下。以后从背包使用回忆册即可反复查看；临时错过赠送不代表永久拿不到。

API Key 是什么？它和 DeepSeek 账号密码有什么区别？0.9+

API Key 是让桌宠调用 DeepSeek 接口的访问凭证。它不是你的 DeepSeek 登录密码、手机验证码、网站提取码，也不是游戏里的道具。请从 DeepSeek 开放平台创建自己的 Key，不要把登录密码填到 API Key 输入处。

我没有 Key，应该去哪里申请？0.9+

Token 是什么？一句话很短也会计算用量吗？0.9+

模型处理的不一定只有你刚输入的那一句，也可能包含角色设定和本次随请求提供的上下文。想了解具体账单，看平台的输入／输出用量，不要只按屏幕上显示的字数估价。Token 与用量官方说明 ↗

怎么控制花费？一直开着桌宠就会一直扣 API 钱吗？0.9+

余额与模型检测成功不等于今后聊天免费，也不代表桌宠能替你设置 DeepSeek 平台消费上限。实际生成回复的用量和计费规则要看后续开放功能及官方账单；游戏内日元不能抵扣 API 费用。不要为了检测反复快速点击按钮。

默认用哪个 DeepSeek 模型？可以选推理模型吗？0.9+

大模型、麦克风识别、预录台词和 SoVITS 到底有什么区别？0.9+
部分负责什么不代表什么
DeepSeek 大模型根据提交的文字内容生成回复有 Key 不等于已经有祥子音色
麦克风与识别接收你的声音并识别输入／指令听见唤醒词不等于已经调用大模型
预录语音播放软件内已有的固定台词不能自动覆盖所有临时生成的句子

可能的语音对话链路是“声音识别为文字 → 大模型生成文字 → 合成为声音 → 播放”，每一段都可能有独立配置、权限和耗时。0.9 实际开放哪些输入与朗读方式，以正式界面为准。

只填 DeepSeek Key 就会用小祥的声音说任意内容了吗？0.9+

不会仅凭 Key 自动获得祥子声线。Key 解决的是大模型接口访问，不包含你本机的祥子语音模型、参考音频、语音运行环境或输出设备配置。

若 0.9 开放动态朗读，还需要对应平台的语音组件能正常生成并播放音频。先把“已经收到文字回复”和“已经生成语音”分开确认；不要为了声音问题反复重新申请 Key。

一定要开麦克风、装语音组件才能聊天吗？0.9+

文字输入、大模型生成、麦克风输入和语音朗读是不同环节，技术上并非同一个开关。但 0.9 最终是否提供纯文字模式、是否能独立关闭朗读，目前还没有确定的玩家操作说明。

发布后以软件提供的输入方式为准；不要认为必须先购买游戏里的麦克风道具才可以配置任何大模型功能，也不要认为安装 SoVITS 就自动有了聊天窗口。是否有阶段／道具限制会在最终说明中明确。

0.9 语音聊天没反应，先检查 Key 还是麦克风？0.9+
  1. 先确认安装的是已经开放大模型功能的版本，不是公开 0.8。
  2. 若界面支持文字输入，先用短文字检查能否获得回复，把网络／Key 问题与识别问题分开。
  3. 若文字正常但声音输入无效，再检查默认输入设备、系统麦克风权限、软件监听状态以及当前动作是否允许输入。
  4. 若已经显示文字回答但听不到朗读，再检查合成组件、输出设备与音量。

0.8 的唤醒词和指令表不能直接当作 0.9 自由对话操作说明；新的唤醒方式与输入流程以发布版为准。

Mac 的 SoVITS 怎么安装？Windows 能装这个 PKG 吗？0.9+

这个 PKG 是 macOS 专属组件，不能拿到 Windows 安装。Windows 的环境和组件请以 Windows 版本说明为准。本页说明组件概念与现有 Mac 安装边界，不代表两个平台的 0.9 语音功能已经同步完成。

能让她说中文吗？现有语音组件为什么偏日语？0.9+

大模型输出语言和最终合成音色／语言是两件事。现有 Mac 组件优先跑通祥子的日语模型与参考音频；这不等于已经提供同样效果的中文动态语音。

把中文直接交给不匹配的语言前端或参考配置，可能出现读音或音色问题。0.9 是否提供中文合成、翻译或其他语言选项尚待正式说明；不要把“模型能生成中文文字”理解成“本地语音已经支持中文”。

文字回复出来了，为什么没有声音？0.9+

文字回复已经出现时，先检查后面的“合成与播放”环节，而不是继续换 DeepSeek Key：

  • 当前版本是否真的开放动态朗读，是否已启用。
  • 对应平台的语音组件和祥子模型是否安装完整，组件能否单独生成样本。
  • 输入语言与合成设置是否匹配，是否显示加载或合成错误。
  • 系统输出设备、应用静音和相应音量是否正确。

第一句可能包含模型加载时间。预录台词能播放，并不能证明动态语音模型也已成功加载；二者应分别检查。

为什么说一句话要等很久？是网络卡还是电脑慢？0.9+

总等待可能分成四段：识别你的话、向 DeepSeek 请求回复、把文字合成为音频、播放。网络和在线服务影响大模型部分，本机 CPU／GPU、内存与模型加载影响本地合成部分。

先用短句测试，观察文字是迟迟不出现，还是文字已出现但声音迟到。刚启动第一次合成通常还要加载环境和模型，不能仅凭第一句判断每次都一样慢。是否支持流式显示、边生成边读或缓存预热，以 0.9 实际发布能力为准，不提前承诺。

出现 401、402、429、500、503 或请求超时怎么办？0.9+

Mac Dev 会把检测结果显示在设置页的密钥下方；保存后自动检测，每次启动也会重新检测，结果不会永久缓存为“可用”。可以点击「重新检测」。按提示处理：

提示怎么办
尚未配置密钥点击设置密钥，粘贴自己的 DeepSeek API Key；不影响原有桌宠玩法。
正在检测等待后台检查完成，不要连续重试。
密钥无效或已被删除（401）检查是否复制完整、是否来自官方平台、是否已经被撤销；用更换密钥重新填写。
账户余额不足（402 或余额不可用）去 DeepSeek 开放平台检查 API 余额，充值到账后重新检测；不用清空游戏存档。
没有访问权限（403）检查平台账号或密钥的访问权限。

超时、网络或返回格式异常检查网络后再检测；这不能直接说明密钥失效或账户没钱。

“连接正常”只表示这次检测时密钥可访问接口且余额可用，不是已经开放聊天，也不保证未来始终可用。反馈请提供脱敏提示、软件版本与操作步骤，不要发送完整密钥。DeepSeek 官方错误码说明 ↗

Key 能发给作者检查、填到本站或截进反馈图里吗？0.9+

不要。本站只有介绍、下载与 FAQ，不需要收集你的 API Key。作者排查问题通常需要的是错误码、版本和复现步骤，不是密钥、验证码或账户密码。

反馈前把密钥和敏感路径遮掉；不要把 Key 放进公开评论、GitHub Issue、聊天截图或共享配置。若已泄露，应在 DeepSeek 开放平台撤销该 Key，检查用量，再按需要创建新的。删除公开消息不代表泄露的旧 Key 自动失效。

Key 会保存在哪里？导出存档会带走它吗？0.9+

Mac Dev 使用 macOS 钥匙串保存原始密钥。按应用数据目录隔离，正式版、Dev 和独立测试档不会因为用了同一台电脑就共享同一条配置。密钥不写入游戏进度、普通偏好文件或 SPET 导出包，界面状态仅包含脱敏文本。

换电脑或切换数据目录后，需要自行重新配置；导入游戏存档不会带入密钥，也不会替你安装语音组件。设置页不提供读取完整旧密钥的操作；需要停用时点击「移除密钥」。移除本机配置不会撤销 DeepSeek 平台上的 Key；若已泄露，还应去官方平台删除该 Key。这里描述的是 Mac Dev 实现，不代替 Windows 的存储说明。

和小祥聊天是本地的吗？什么内容会发给 DeepSeek？0.9+

调用云端 API 时，实际提交的消息会发往服务端处理，因此不能把它称为完全离线聊天。本地语音合成只表示合成环节在本机运行，不能据此推断上游大模型也在本地。

具体发送哪些角色设定、上下文或游戏状态，需以 0.9 最终实现与隐私说明为准。不要向聊天输入你不愿提交给服务提供方的密码、验证码或私密资料，也不要仅因填了 Key 就假定软件有读取全部屏幕和文件的功能。此处不承诺第三方服务“绝不记录”或“永不保留”数据。

她会一直记住我说的话吗？清空聊天是不是就不计费了？0.9+

多轮对话需要软件提供必要的上下文；DeepSeek 的聊天 API 不会自动替客户端维护所有对话上下文。应用的聊天记录、长期记忆、跨次启动保留、清空和随存档迁移，仍需软件自己实现，0.9 的具体规则尚未公布。官方多轮对话说明 ↗

“接口不自动维护上下文”不等于服务提供方从不保留请求日志。清空本机聊天也不能撤销已经提交的请求或已经产生的用量。

AI 说送我钱、升好感、解锁第四阶段，真的会生效吗？0.9+

聊天生成的一句话不等于系统已经执行游戏操作。余额、信任度、背包、解锁和结算，要以游戏实际状态及明确的功能说明为准；不能因为她在对话里说“已经送给你”就当作到账。

0.9 没有公布的经济联动、自动操作、联网搜索、读屏或控制程序能力，这里不会提前写成已支持。已有第四阶段仍可先看本页「信任与解锁」；模型输出的攻略也可能出错，具体门槛以界面和正式规则为准。

不填 Key、不想用大模型，能继续只玩桌宠吗？0.9+

可以。0.8 原有桌面陪伴、经营和固定语音玩法不依赖 DeepSeek Key；当前 Mac Dev 没有配置密钥时也能继续使用这些功能。没有 Key 时不会发起大模型生成请求，不用为了保留旧玩法先清空进度。

已经配置但不想继续检测，可在「设置 → 大模型与语音」点击「移除密钥」。这会移除当前数据目录对应的本机配置，停止后续启动使用这条密钥检测；不会删除游戏进度，不会卸载 SoVITS，也不会删除 DeepSeek 平台上的 Key。后续正式 0.9 的聊天开关与玩法以发布说明为准。

安装与报错

先保留原文件和存档，再按提示检查。

Windows 报“语音启动失败／找不到 SakikoVoiceWorker.exe”怎么办？Windows+

如果用过网盘云解压，请先重新下载完整压缩包，在电脑本地完整解压。

例如报错中出现 …\Voice\SakikoVoiceWorker.exe、系统找不到指定的文件，或路径位于 AppData\Local\Temp、带 .zip 的临时目录，常见原因是从压缩包预览里直接运行、云解压后只下载了部分文件，导致语音工作进程没有完整落地。

  1. 正常退出桌宠，保留原有存档，不要删数据目录。
  2. 不要云解压，也不要只下载 EXE。重新下载网盘原始完整压缩包。
  3. 用本机解压工具全部解压到一个新的空文件夹。
  4. 检查同目录 Voice/SakikoVoiceWorker.exe 是否存在，再从新文件夹运行 SakikoPet.exe。
  5. 仍缺文件时检查下载／解压是否报错，以及安全软件是否隔离了文件；只对确认来源可信的文件处理，不要直接关闭全部防护。

云解压是可能原因之一，不是所有语音报错的唯一原因。文件齐全仍失败时，请附完整错误文本、版本、系统与复现步骤反馈，别只截图最后一行。

Voice 文件齐全，但语音仍不能启动或听不见？Windows+

先区分「识别进程启动失败」「麦克风没输入」和「音频播放没声音」。文件齐全不代表麦克风已开启：检查背包监听、Windows 默认输入设备和应用麦克风权限；台词没声则再检查应用音量、系统混音器和输出设备。

用本站提供的完整对应 Windows 安装包，不混用其他版本 Voice 或从 Mac 包复制组件。仍失败时保留原始错误和运行日志供反馈；不要靠删存档或随机覆盖模型排查。

Mac 程序坞明明在，为什么“仅程序坞”不能选？macOS+

精确识别需要可见的底部程序坞，以及辅助功能、屏幕录制权限。到桌宠设置检查授权，再到 macOS 对应权限页核对当前安装的 SakikoPet；授权后按系统提示重新打开。

程序坞自动隐藏、位于侧边、未显示或无法可靠识别时，范围会锁定整个屏幕，让她在屏幕底部行走，这是回退行为。全屏应用里也使用整屏范围，不把看不见的程序坞当边界。

较早的安装包切换行走范围需要重启，后续已修为即时生效；请以实际下载版本为准。更换 App 后不要只看旧条目的勾选，也不要自行重置所有隐私权限。

Mac 要给哪些权限？会默认录音或上传吗？macOS+

按你使用的功能授权即可：麦克风用于本地唤醒和语音识别；辅助功能用于跨应用输入等操作；屏幕录制用于桌面捕获、截图和部分程序坞／舞台识别。

普通陪伴不需要把所有功能都开启。麦克风还要在背包主动开启；0.8 的唤醒识别是离线处理，不是把语音发给在线聊天模型。权限被拒绝时，对应功能可能不可用，先查看应用里的具体提示。

能让她安静一点吗？调低音量会不会少赚钱？双端+

在状态／设置的偏好里调整说话音量与说话间隔。调低台词音量不会降低工资；桌面舞台和弹琴的音量要在相应控制界面里分别调整。

如果想暂时停止全部活动，可使用暂停或隐藏；这些状态会影响部分活动和计时，与单纯调低声音不同。

反馈 Bug 应该提供什么？双端+
  • Windows 或 macOS，以及系统版本；Mac 还注明 M 系列还是 Intel。
  • 桌宠的完整版本号、从哪里下载、是否云解压、如何安装。
  • 从什么状态、按了哪些按钮或说了什么词后出问题。
  • 完整报错文本或截图，是否能稳定复现，是否只在某个应用／全屏空间发生。

截图先遮掉个人路径、聊天内容等隐私。保留原存档与报错记录，不要为了“修一下”先清空游戏。可通过版本视频下的评论或作者公开渠道反馈。

存档与更新

替换程序不等于删除存档，搬家前先备份。

从 0.7 更新到 0.8，存档会保留吗？双端+

正常更新时，存档与程序分开保存。先正常退出旧版，再安装或解压新版，不要同时运行两个版本。Mac 用新 App 替换旧 App，通常会继续读取同一系统用户下的正式存档；Windows 搬动程序文件夹也不会自动变成新进度。

更新前建议完整备份。不要删除 Application Support 或 LocalAppData 下的游戏数据，也不要把正式版与 Dev 的独立数据目录混在一起。歌曲、截图等文件的保存方式与游戏进度不同，需要自行保留。

存档在哪里？复制程序到另一台电脑就能带走吗？双端+

Windows 主存档通常位于当前用户的 %LocalAppData%/SakikoPet；部分旧模块可能有独立目录。Mac 正式存档位于 ~/Library/Application Support/SakikoPet.Mac。它们不在 App 包或 EXE 本身里面。

只复制程序不会自动迁移进度。跨电脑前先完整备份；不要只挑一个 commerce 文件覆盖，因为余额、库存、结算和阶段记录需要保持一致。Mac 的 Dev 存档独立于正式版。

怎么导出／导入 .spet？会清空本机存档吗？macOS+

已包含迁移功能的 Mac 包，可在「设置 → 权限与存储 → 存档备份与恢复」操作。导出要设置密码，密码无法找回；加密文件保存成功后才询问是否备份、清空并重启，选择保留则不清空本机进度。

导入会替换游戏进度，先备份旧档并要求确认，完成后重启；偏好、大小、音量、权限和应用绑定保留。同一存档编号在本机核销，成功后还会向选中的加密文件回写已导入标记；已标记文件不能再次导入。导入前的副本不具有联网全局核销保证。

旧 0.8 包可能没有入口。Windows 是否支持取决于对应安装包；目前不能承诺两端已经完成双向互导验收。不要直接把 JSON 改后缀为 SPET，也不要把可编辑开发文件当玩家导入文件。

存档损坏、读档报错时能直接删除文件吗？双端+

先别删。正常退出程序，备份完整数据目录与报错，再反馈当前版本和触发过程。删除单个经济或结算文件，可能让进度、余额与事务记录不一致。

不支持的未来存档版本、权限不足和真正损坏是不同问题；不要把它们都当成空档处理。升级后打不开时也先保留旧数据，按作者确认的恢复步骤操作。
